# Algorithm_Design_Guess_My_Number_Game
This is the project for Design and Analysis of Algorithms course I made with my group member in university. There are 2 parts to this - C++ and HTML.

## Table of Contents

- [Tools](#tools)
- [Features](#features)
- [Notes](#notes)
- [Credits](#credits)

## Tools
- C++
- Javascript
- CSS
- HTML

## Features
- C++ core algorithm implementation.
- HTML game similar to the real life Guess My Number children's game.
- Shows an optimal strategy to have guessed the unknown number using binary search.
- Demo video is included which shows how to play the game.
- The Description of the problem, Asymptotic Analysis of the algorithm and the Dry Run Analysis is included as a document. It is highly recommended to read it.

## Notes
- The core functionality and the algorithm code is provided in C++, on which the actual game is based.
- The coded game is provided in HTML.
- The way this project is structured was required by our professor. We were given a list of Problems from the Algorithm design course book and we had to solve them in C++, and for the second part we had to make a game based on the algorithm.
